# Write a Commit Message for a UserService API Update

## Background

The UserService team has been standardising the public REST API surface. A
developer on the team has updated the user-listing endpoint in the `api` module
and staged the change locally. The change is ready to commit, but no commit
message has been written yet.

You have been asked to review the staged change and produce an appropriate
commit message for it.

To set up the repository with the staged change, run:

```bash
bash inputs/setup.sh
```

## Your Task

After running the setup script, inspect the staged changes and write a commit
message for them. Save the commit message to `commit-message.txt`.
