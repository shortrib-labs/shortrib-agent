# Write a Commit Message for Staged Changes

## Background

The team has been expanding the user profiles module of an internal web platform. A developer finished a chunk of work this morning and staged the changes, but before they could write the commit message they got pulled into a meeting. You've been asked to pick up where they left off: inspect the staged changes, figure out what they accomplish, and write an appropriate commit message for the changeset.

The diff of the staged changes is saved at `inputs/diff.txt`. The changes span three files in the `src/profiles/` module.

## What to Do

1. Read `inputs/diff.txt` to understand what the staged changes introduce.
2. Write a commit message for these changes and save it to `commit-message.txt`.

The commit message should reflect the nature and intent of the changes accurately. The team follows standard commit message conventions, so make sure the message is well-formed and professional — the kind of message that will make sense to a reviewer looking at the git log six months from now.
